# Evidencia 1 — Suma

Primera prueba de la secuencia. El resultado se representa con cuatro bits.

| Señal o dato | Valor binario | Valor decimal / descripción |
|---|---:|---|
| Operación | `00` | Suma |
| Color RGB | `010` | Verde |
| Entrada `A` | `0101` | 5 |
| Entrada `B` | `0011` | 3 |
| Salida esperada `Y` | `1000` | 8 |

En esta carpeta se puede guardar la captura de GTKWave correspondiente a la prueba de suma.
