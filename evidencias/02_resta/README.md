# Evidencia 2 — Resta

Segunda prueba de la secuencia. El resultado se representa con cuatro bits.

| Señal o dato | Valor binario | Valor decimal / descripción |
|---|---:|---|
| Operación | `01` | Resta |
| Color RGB | `100` | Rojo |
| Entrada `A` | `0111` | 7 |
| Entrada `B` | `0101` | 5 |
| Salida esperada `Y` | `0010` | 2 |

En esta carpeta se puede guardar la captura de GTKWave correspondiente a la prueba de resta.
