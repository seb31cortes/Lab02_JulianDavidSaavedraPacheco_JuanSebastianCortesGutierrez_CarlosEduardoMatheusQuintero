# Evidencia 3 — AND

Tercera prueba de la secuencia. La operación se aplica bit a bit.

| Señal o dato | Valor binario | Valor decimal / descripción |
|---|---:|---|
| Operación | `10` | AND bit a bit |
| Color RGB | `001` | Azul |
| Entrada `A` | `0011` | 3 |
| Entrada `B` | `1001` | 9 |
| Salida esperada `Y` | `0001` | 1 |

En esta carpeta se puede guardar la captura de GTKWave correspondiente a la prueba AND.
